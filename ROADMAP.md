## ✅ Project Definition of Done

- Problem and intended user are clear in the README
- Setup works from a clean checkout
- Core behaviour has tests or repeatable checks, including edge cases
- Design and trade-offs are explained
- Git history shows incremental work, no secrets or private data
- Demo, screenshots or sample output included
- Limitations and next steps are honest
- I can explain my own code without notes

## 🧭 Roadmap Rules

1. College syllabus first
2. Depth beats checkbox collecting
3. Projects are evidence
4. DSA is a long game
5. GitHub is a record of real work
6. Health and sleep are part of the plan
7. Review every 4 weeks and adjust dates without treating change as failure

## ✂️ If I Fall Behind, Cut In This Order

1. CodeChef and other optional contests
2. LeetCode volume
3. Project polish and optional extensions
4. New optional topics (C++, frameworks, deployment)

Core coursework and Java/DSA fundamentals never get cut.
